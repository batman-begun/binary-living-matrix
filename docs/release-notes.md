Three animated shapes share one binary glyph field. WOMAN breathes, OCEAN rolls, and BRAIN responds to prompt input. Touch creates a depression and a traveling rebound on any animated shape.

[Live showcase](https://batman-begun.github.io/binary-living-matrix/)

This release includes the Lab controls, adaptive quality, reduced motion, a browser-recorded demo and a reproducible Chromium baseline. The included performance figures describe an emulated mobile viewport on the CI host. See the device UAT notes for physical-device checks.
