# Visual rules

- Use ivory `#F7F7F4` behind the matrix.
- Draw the field using 0 and 1 glyphs in a single fixed-size monospace font. Shape contours are built from glyph placement and ink.
- Keep WOMAN legible from the face and shoulders down to the waist, hip and upper thigh.
- Keep transitions and touch reactions continuous. The base field is shared by WOMAN, OCEAN and BRAIN.
- Leave enough exposed canvas to touch. Prioritize readable controls and keep BRAIN visible above the prompt when the mobile viewport contracts.
